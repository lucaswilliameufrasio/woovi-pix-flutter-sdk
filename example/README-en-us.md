# Flutter Pix checkout example

[Português (Brasil)](README.md)

Demonstration app for the `woovi_pix_flutter` package. It talks to the Go backend in `../examples/backend`; it never receives the Woovi AppID.

- [Run the local demo](../docs/en-us/demo.md)
- [Test with the Woovi sandbox](../docs/en-us/sandbox.md)
- [Run tests and builds](../docs/en-us/development.md)
- [Project overview](../README-en-us.md)

> For local testing only. The simulated QR is fictional: do not pay with a real bank. The sandbox session token is embedded in the example app: do not distribute an APK containing this token or use this authentication mechanism in production.
